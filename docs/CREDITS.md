# 来源与致谢

本仓库不是从零开始的独立发明。协议知识来自前人的实测，驱动能力来自 vJoy 项目。
下面把每一样东西的来路写清楚，避免把别人的成果写成自己的。

---

## 1. 串口协议知识

### Matsemann/mDjiController

- 仓库：https://github.com/Matsemann/mDjiController
- 许可证：**Apache-2.0**
- 是什么：把 DJI 遥控器接到 PC 上当作模拟器手柄使用的 C++ 项目，
  是这一类项目的源头（2014 年创建，2024 年仍在更新）
- 本仓库从它得到了什么：**「主动发 PING 才能打开数据流」这个关键认识**，以及
  `0x55 0x26` / `0x55 0x3A` 两类帧的存在与长度、SBUS 量纲（364~1684，中位 1024）
- 说明：本项目**没有引用它的源码**，只使用了其中已经公开、且在本机独立复测通过的协议事实。

> 备注：`Timebutt/mDjiController` 是本仓库的 fork（2017 年创建），不是源仓库。
> 引用时请指向 `Matsemann/mDjiController`。

### MavicMiniControllerAsGamepad

- 这个名字出现在用户提供的参考脚本 `dji_vjoy.py` 的注释里，与 mDjiController 并列作为协议来源。
- **本仓库未能核实到它的具体仓库地址**，因此不在此处给出可能错误的链接。
  如果这个项目的作者看到本仓库，欢迎提 issue 补充准确出处。

### 用户提供的 `dji_vjoy.py`

- 来源：由本机用户提供（本地路径 `...\pdd\tools\dji_vjoy.py`），**非本仓库原创**。
- 本仓库从它得到了什么：完整的帧长表、轴偏移假设（13/16/19/22/25）、
  vJoy 轴槽双写的处理方式（`0x33+0x35`、`0x34+0x36`）。
- **本仓库未收录该脚本本体**（原作者与许可证未知）。如果你需要它，请自行向提供者获取。
- 本仓库对它的两处结论做了修正，并已实测验证：
  1. 按键只有 3 个（`0x40/0x20/0x80`）→ 实测 `[29]` 是 8 位掩码，实际出现 4 个位
  2. 轴帧按 5 个轴解析 → 实测是每 3 字节一组、共 8 组数据

## 2. 虚拟手柄驱动

### vJoy

- 项目：vJoy（虚拟游戏手柄驱动），本仓库适配的版本是 **vJoy 2.1.9.1**
- 本仓库的使用方式：运行时通过 `LoadLibrary` 加载 `vJoyInterface.dll` 并调用其公开 API
  （`vJoyEnabled` / `AcquireVJD` / `SetAxis` / `SetBtn` / `UpdateVJD` 等）。
  **本仓库不包含、也不分发 vJoy 的驱动或 DLL 二进制文件。**
- vJoy 自身的许可证与使用条款以 vJoy 官方项目为准，使用前请自行阅读。

### 本机实测得到的 API 事实（原创记录）

以下都是在本机反复试出来的，不是抄来的文档结论：

- `UpdateVJD(UINT rID, JoystickState* pState)` **必须传完整状态结构**；传 `NULL` 或只用单参
  会直接崩溃（0xC0000005）
- 轴范围是 `0..32767`，中点 `16383`（不是 65535）
- `GetVJDAxisMax` 是 3 个参数
- 本机设备 1 只有 5 个有效轴槽（详见 `docs/PROTOCOL.md`）

## 4. 本仓库原创的部分

- `pc/VJoyPC.cpp`：C++ 实现的串口桥接与 vJoy 写入，包含
  - 默认 USB 直连、找不到自动回退 UDP 的双链路
  - 每轴 中位 / 反向 / 灵敏度（滑动速率）三个手感参数
  - 不依赖「打开-关闭-重开」的串口探测方式（规避驱动释放延迟导致的 ACCESS_DENIED）
  - 用 `QueryDosDeviceA` 枚举端口而不是逐个 `CreateFile` 试探
- `pc/tools/axis_probe.py`、`pc/tools/button_probe.py`：轴位与按键位图的实测工具
- `docs/PROTOCOL.md`：全部实测数据的整理与验证状态标注
- 所有标注为「实测」的结论，都是在本机上复测通过的
